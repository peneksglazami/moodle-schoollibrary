ТЗ: Разработка плагина «Школьная библиотека» для Moodle 4.0+

1. Общие требования
- Тип плагина: модуль курса (activity module).
- Имя плагина: mod_schoollibrary.
- Совместимость: Moodle 4.4.1 и выше.
- Версия PHP: 8.0 и выше.
- Язык интерфейса: русский, обязательно создать языковые файлы en и ru.
- Плагин должен быть готов к установке в папку /mod/schoollibrary без доработок.

2. Назначение модуля
Модуль используется учителем внутри конкретного курса для учета выдачи книг школьной библиотеки.

Одна запись = одна книга, выданная одному студенту.

Книга задается свободным текстом, без справочника книг, без автодополнения и без отдельного каталога.

3. Доступ
- Управление модулем доступно только учителю курса и менеджеру.
- Студенты не имеют доступа к интерфейсу модуля.
- Студенты могут только получать уведомления, если они включены.

4. Работа с группами и студентами
В форме выдачи книги:
- сначала учитель выбирает группу курса;
- после выбора группы список студентов должен показывать только активных студентов выбранной группы;
- студенты других групп не отображаются;
- неактивные и удаленные пользователи не отображаются;
- выбранный студент обязательно проверяется на сервере на принадлежность к выбранной группе.

Ранее была ошибка: после выбора группы список студентов оставался пустым. Это должно быть исправлено и проверено.

5. Поля выдачи
Каждая запись должна содержать:
- группа;
- студент;
- название книги, свободное текстовое поле;
- дата получения;
- планируемая дата возврата;
- фактическая дата возврата;
- статус;
- комментарий, необязательно;
- кто выдал;
- кто принял возврат.

6. Даты
- Дата получения выбирается вручную, по умолчанию текущая дата.
- Планируемая дата возврата по умолчанию = дата получения + 14 дней.
- Срок выдачи по умолчанию должен быть настраиваемым.
- Дата возврата не может быть раньше даты получения.
- При возврате книги фактическая дата возврата проставляется автоматически, если учитель не указал другую.

7. Статусы выдачи
Использовать статусы:
- Активна;
- Возвращена;
- Просрочена;
- Утеряна.

Требования:
- статус «Просрочена» должен определяться автоматически;
- при возврате статус меняется на «Возвращена»;
- статус «Утеряна» может быть установлен вручную;
- для возвращенных и утерянных записей уведомления о просрочке не отправляются.

8. Интерфейс учителя
Нужны:
- список всех выдач в модуле;
- фильтры по статусу, группе, поиску по студенту и книге;
- таблица с колонками: группа, студент, книга, дата получения, дата возврата, факт возврата, статус, действия;
- кнопка добавления выдачи;
- редактирование записи;
- возврат книги;
- удаление записи с подтверждением;
- импорт из CSV;
- экспорт в CSV.

9. Иконка модуля
У плагина должна быть корректная иконка.
Нужно предусмотреть файл иконки, например:
- pix/icon.svg

Иконка должна отображаться в списке активностей курса после установки и очистки кеша.

10. Уведомления
Реализовать уведомления через стандартный механизм сообщений Moodle.

События:
- книга выдана студенту;
- книга возвращена;
- напоминание о скором возврате;
- книга просрочена.

Настройки:
- включать/выключать уведомления;
- количество дней до даты возврата для напоминания, по умолчанию 3 дня.

11. Импорт и экспорт
Импорт из CSV:
- импорт выдач;
- пользователь ищется по email;
- проверяется, что пользователь является активным студентом текущего курса;
- проверяется принадлежность к группе;
- название книги — свободный текст;
- даты поддерживают формат ГГГГ-ММ-ДД и ДД.ММ.ГГГГ;
- после импорта показывается отчет об ошибках.

Экспорт в CSV:
- экспорт текущего списка с учетом фильтров;
- кодировка UTF-8;
- разделитель точка с запятой;
- выгружаются: группа, студент, книга, даты, статус, комментарий.

12. Технические требования
- Использовать стандартные механизмы Moodle.
- Не использовать сторонние библиотеки без необходимости.
- Использовать группы курса Moodle, не создавать собственные таблицы групп.
- Реализовать права доступа через capabilities.
- Реализовать Privacy API.
- Реализовать поддержку резервного копирования и восстановления.
- Код должен быть чистым, без заглушек и псевдокода.
- Все пользовательские тексты выносить в языковые файлы.

13. Структура результата
Фрилансер должен передать итоговую папку модуля, готовую для загрузки:

mod/schoollibrary/

Внутри должны быть все необходимые файлы, включая:
- version.php;
- lib.php;
- index.php;
- view.php;
- mod_form.php;
- страницы выдачи, возврата, удаления, импорта и экспорта;
- db/;
- lang/;
- classes/;
- pix/;
- backup/;
- settings.php при необходимости.

14. Требования к сдаче работы
Передать:
1. Полную папку плагина, готовую к установке.
2. Краткую инструкцию по установке.
3. Список настроек.
4. Пример структуры файла импорта.
5. Описание найденных ограничений, если они будут.

15. Критерии приемки
- Плагин устанавливается на Moodle 4.0+ без ошибок.
- Модуль добавляется в курс.
- Иконка модуля отображается после очистки кеша.
- Учитель может создать выдачу.
- После выбора группы отображаются только студенты этой группы.
- Пустой список студентов не остается без объяснения, если в группе нет активных студентов.
- Книга вводится свободным текстом.
- Даты и статусы работают корректно.
- Просрочка определяется автоматически.
- Возврат книги меняет статус на «Возвращена».
- Импорт и экспорт работают.
- Студенты не имеют доступа к управлению модулем.
- После исправлений фрилансер передает полную актуальную папку модуля, а не только измененные файлы.
