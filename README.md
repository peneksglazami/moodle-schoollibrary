# Moodle School Library

`mod_schoollibrary` is a Moodle activity module for managing school-library loans. This repository currently contains the infrastructure and minimal installable activity skeleton only; loan workflows are intentionally deferred.

The authoritative functional specification is [`docs/TZ.md`](docs/TZ.md). Start with [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) and [`docs/TESTING.md`](docs/TESTING.md).
