# Moodle School Library

Bootstrap repository for the `mod_schoollibrary` Moodle activity. The repository root is the plugin root and must be installed at `<moodle-root>/mod/schoollibrary`.

Functional requirements are in [`docs/TZ.md`](docs/TZ.md). Moodle 4.4.1 with PHP 8.3 is the mandatory primary test target. See [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) and [`docs/TESTING.md`](docs/TESTING.md).
